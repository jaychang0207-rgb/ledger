# 班表來源

這個資料夾放航班查詢 App 的班表（Excel）。

- **檔名＝生效日期**，例如 `2026-11-16.xlsx`：從這天起使用這份班表，直到下一份的日期。
- 每份需包含工作表「每日班次明細」（一列一班，需有 星期、基地、航點、班號、機型限制、時間、機尾號 欄）和「機隊清單」。
- 時間格式：`8:20-16:25`、`23:30-7:15(+1)`，皆為台灣時間。

## 更新班表

1. 把新的 Excel 用生效日期命名後上傳到這個資料夾（GitHub 網頁「Add file → Upload files」即可），提交到 `main`。
2. GitHub Actions「更新航班資料」會自動執行 `scripts/build_flights.py`，產生 `flights/data/flights.json`。
3. 不換班表也沒關係：每週一 00:17（台灣時間）會自動重算，查詢範圍永遠是「上週一」到「今天＋365 天」。

舊班表在完全過期後會自動不再使用，可以保留或刪除。
